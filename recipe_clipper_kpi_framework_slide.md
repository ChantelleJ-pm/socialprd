# Recipe Clipper KPI framework slide

## Title
Recipe Clipper KPI framework

## Subtitle
Measure the product across adoption, value delivered, experience quality, and scale constraints.

## North-star callout

- **North-star metric**
  - **Successful saves per active user**
- Why this is the best whole-product KPI:
  - combines actual usage with delivered value
  - is stronger than raw click volume alone
  - aligns to the product goal of making MyRecipes the place users save recipes from across the web

## Four KPI layers

### 1. Adoption
- Add Recipe button clicks
- % of active users who start a save
- Save Recipe button clicks

### 2. Value delivered
- Successful recipes saved
- Successful saves per active user
- Share of all MYR saves from Recipe Clipper

### 3. Experience quality
- Save URL success rate
- Avg save-click time
- Error rate by type

### 4. Coverage constraints
- External-brand save share
- Unsupported-site rate
- Supported Sites engagement

## Stakeholder takeaway

- For the product as a whole, we should not evaluate Recipe Clipper on one operational metric alone
- We should measure:
  - **adoption**
  - **value delivered**
  - **experience quality**
  - **what is limiting scale**

## Recommended headline

- **Headline KPIs**
  - Successful saves per active user
  - Save URL success rate
  - Share of all MYR saves from Recipe Clipper

- **Diagnostic KPIs**
  - Add Recipe button clicks
  - Avg save-click time
  - Unsupported-site / user / product error mix
