# Recipe Clipper KPI framework with actuals

## Title
Recipe Clipper KPI framework with current actuals

## Subtitle
Post-mid-Feb snapshot from current exports (2/19-3/18), with missing user-based KPIs called out.

## North-star recommendation

- **Recommended north-star:** Successful saves per active user
- **Status:** not available in the current export
- **Closest current actuals:**
  - **2,151** successful recipes saved
  - **52.1%** average daily save attempt success rate

## KPI layers with actual data

### 1. Adoption
- **3,767** Add Recipe clicks
- **108.2** average Add Recipe clicks per 100K sessions
- **3,911** Save Recipe clicks
- **Gap:** % of active users who start a save is not in the current export

### 2. Value delivered
- **2,151** successful recipes saved
- **52.1%** average daily save attempt success rate
- **0.08%** average share of all MYR saves from Recipe Clipper
- **Gap:** saves per active user is not in the current export

### 3. Experience quality
- **3.84s** average save-click time
- **24.5%** user-side error rate
- **12.6%** external/domain error rate
- **10.0%** product-side error rate

### 4. Coverage constraints
- **85.3%** external-brand share of successful saves
- **92.1%** of external errors are unsupported sites
- **487** unsupported-site failures in the trusted period
- **386** Supported Sites clicks (**11.3 per 100K sessions**)

## Stakeholder takeaway

- We can already measure the product well across adoption, value delivered, experience quality, and scale constraints
- The biggest current blind spot is **user-based outcome metrics** like:
  - successful saves per active user
  - % of active users saving
  - repeat usage / retention

## Footnote
Current actuals use the trusted post-mid-Feb period (**2/19-3/18**) wherever possible. Share of all MYR saves should be treated as the exported definition unless analytics confirms otherwise.
